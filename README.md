# 📱 에이닷(A.) 앱 리뷰 NLU 피드백 분석

구글 플레이스토어에서 에이닷 앱 리뷰를 수집해서 **음성인식이랑 AI 통화 요약(NLU)에 사용자들이 어떤 불만을 느끼는지** 분석한 프로젝트

---

## 📌 분석 개요
* **분석 대상:** 에이닷 앱 리뷰 500건 (관련도 높은 순)
* **사용한 도구:** Python, Google Colab, Pandas, KoNLPy (Okt), Matplotlib, Seaborn
* **주요 작업:**
  1. 리뷰 텍스트 수집 및 정제
  2. 명사 빈도 분석으로 주요 키워드 확인
  3. 키워드 기준으로 리뷰 카테고리 분류
  4. NLU(음성/요약) 관련 불만 사항 세부 분류 및 시각화

---

## 📊 주요 분석 결과

### 1. 리뷰 카테고리 분류
| 카테고리 | 비중 | 건수 | 주요 내용 |
| :--- | :---: | :---: | :--- |
| **NLU_음성인식/AI요약** | **83.4%** | 417건 | 음성인식, STT, 통화 요약 등 AI 기능 피드백 |
| **System_앱성능/안정성** | **6.6%** | 33건 | 앱 튕김, 로딩 지연, 업데이트 오류 등 |
| **Feature_기능/사용성** | **6.2%** | 31건 | UI/UX, 캐릭터, 기능 개선 요청 등 |
| **General_일반의견** | **3.8%** | 19건 | 기타 짧은 의견 |

> 전체 리뷰의 **83.4%**가 음성인식과 AI 요약 기능에 몰려 있어 유저 만족도를 결정하는 가장 중요한 요소임을 확인

---

### 2. NLU 세부 문제점 분석 (417건 대상)
| 세부 문제 유형 | 비중 | 건수 | 주요 불만 내용 |
| :--- | :---: | :---: | :--- |
| **AI 요약/이해** | **37.6%** | 157건 | 통화 내용을 잘 못 요약하거나 엉뚱하게 이해함 |
| **기타** | **30.9%** | 129건 | 카테고리에 안 걸린 일반 NLU 피드백 |
| **녹음/음성 품질** | **13.9%** | 58건 | 마이크 소리가 작거나 녹음 상태가 안 좋음 |
| **STT+AI 복합** | **9.4%** | 39건 | 글자로 잘못 바뀐 게 AI 요약 오류로 이어짐 |
| **STT 인식/변환** | **8.2%** | 34건 | 발음이나 줄임말을 텍스트로 잘못 바꿈 |

## 💡 결론 및 개선 아이디어

1. **AI 요약 정확도 개선이 최우선**
   * 불만 중 **AI 요약/이해(37.6%)** 비중이 가장 큼
   * 단순히 말소리를 글자로 바꾸는 것보다 **전체 맥락을 정확히 이해하고 요약하는 모델 개선**이 제일 필요

2. **음성 변환 오류 연결 차단**
   * 글자가 틀리게 바뀌어 AI 요약까지 엉뚱해지는 문제를 줄이기 위해 **음성-텍스트 변환 단계 보정**이 필요

3. **녹음/음질 전처리 보완**
   * 소리가 작거나 잡음 때문에 인식이 안 되는 경우(13.9%)를 줄이기 위해 음성 입력 시 **잡음을 줄여주는 필터**로 보완
